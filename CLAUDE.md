# Francophone-American Startup Network (FASN) website

Follow `.claude/skills/fasn-website/SKILL.md` — it is the source of truth for product, brand and trust rules
(bilingual EN/FR, Connect → Build → Grow, no fabricated partners/reviews/credentials/funding, demo data labeled).

## Stack
Next.js (App Router, static export) + React + TypeScript + Tailwind CSS v4. Deployed to GitHub Pages by
`.github/workflows/deploy.yml`.

## Layout
- `src/app/[locale]/…` — pages; every page exists in `/en/` and `/fr/`.
- `src/i18n/dictionaries/{en,fr}.ts` — all UI strings. `fr` is typed against `en`; add keys to both.
- `src/data/` — demo fixtures (`demo: true`, shown with a “Demo” badge) and official resource links.
- `src/components/` — UI; `forms/` holds the Join, Contact, Login, Waitlist and Request-a-Quote forms.
- `src/lib/` — routes, SEO metadata, validation, form submission.
- `public/images/illustrations/` — original SVGs generated by `scripts/generate-illustrations.py`.

## Checks (run before pushing)
```
npm run typecheck && npm test && npm run build
CHROMIUM_PATH=/opt/pw-browsers/chromium-1243/chrome-linux64/chrome npm run test:e2e   # sandbox; omit var elsewhere
```
